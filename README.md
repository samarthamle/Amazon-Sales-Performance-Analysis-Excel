# 📊 Amazon Sales Performance Analysis using Microsoft Excel

## 📌 Project Overview

This project analyzes Amazon sales data using Microsoft Excel to uncover valuable business insights. The analysis includes data cleaning, PivotTables, PivotCharts, KPI creation, and an interactive dashboard.

The objective is to help businesses understand sales performance, customer behavior, payment preferences, and order status.

---

## 🎯 Objectives

- Analyze category-wise total sales
- Identify top-selling products
- Analyze city-wise sales performance
- Study payment method usage
- Analyze order status distribution
- Identify top customers based on spending
- Build an interactive Excel dashboard
